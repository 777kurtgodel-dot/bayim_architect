# Сайт «Байым»

Корпоративный сайт архитектурно-строительной компании «Байым» с админ-панелью, в которой заказчик сам меняет всё содержимое: услуги, проекты и фотографии, сотрудников, новости, тексты страниц, контакты.

**Стек:** Next.js 16 + Payload CMS 3 + PostgreSQL. Один сервер, один Docker Compose, HTTPS через Caddy.

## Что есть на сайте

| Раздел | Адрес | Что внутри |
| --- | --- | --- |
| Главная | `/ru` | первый экран, услуги, избранные проекты, принципы, этапы, отзывы, вопросы, новости, форма заявки |
| Услуги | `/ru/services/…` | отдельная страница на каждую услугу: для кого, что входит, как проходит работа, какие данные нужны, результат, своя кнопка и форма |
| Проекты | `/ru/projects/…` | фильтры по типу объекта, услуге и статусу; кейс: задача, решение, состав работ, галерея (фото, визуализации, планы), результат |
| О компании | `/ru/about` | подход, принципы, компетенции, команда |
| Этапы работы | `/ru/process` | путь клиента от обращения до реализации |
| Вопросы и ответы | `/ru/faq` | по категориям |
| Новости | `/ru/news` | |
| Контакты | `/ru/contacts` | телефон, WhatsApp, Telegram, почта, адрес, карта и кнопка «Открыть в 2ГИС», форма |
| Политика | `/ru/privacy` | политика обработки персональных данных |

Кыргызская версия (`/ky`) уже заложена: интерфейс переведён, у каждого текста в админке есть переключатель языка. Включается галочкой **Настройки сайта → Языки**, когда тексты переведены. До этого `/ky` отдаёт 404 и не попадает в поиск.

## Админ-панель (`/admin`)

- **Заявки** — все обращения с сайта: имя, телефон, услуга, регион, стадия проекта, описание, приложенные файлы, источник (utm-метки, откуда пришёл). Статусы (новая → в работе → встреча → КП → договор / отказ / спам), ответственный, заметки. Выгрузка в Excel (CSV) с учётом фильтра.
- **Главная админки** — новые заявки, заявки за 7 и 30 дней, воронка по статусам, какие услуги запрашивают, откуда приходят заявки, быстрые ссылки.
- **Контент** — проекты (с черновиками и предпросмотром), услуги, команда, отзывы, вопросы, новости, типы объектов, медиатека (картинки автоматически сжимаются в WebP и нарезаются под разные экраны), тексты страниц «Главная», «О компании», «Этапы работы».
- **Настройки** — контакты и соцсети, ссылка на компанию в 2ГИС (по ней работают кнопка и точка на карте), получатели уведомлений, коды аналитики, языки, политика конфиденциальности, SEO по умолчанию; пользователи.

### Доступ

В админку входят по почте и паролю. Роль одна — администратор: у каждого пользователя полный доступ к заявкам, контенту, настройкам и другим пользователям. Без входа заявки, файлы к ним и список пользователей недоступны.

- Первого пользователя создают на странице `/admin` при первом запуске сайта.
- Последнего пользователя удалить нельзя, чтобы не потерять доступ.
- После 7 неверных попыток входа учётная запись блокируется на 15 минут.
- Сессия входа действует 7 дней.
- «Забыли пароль?» присылает ссылку на почту, если на сервере настроен SMTP (см. «Уведомления о заявках»).

## Локальный запуск

Нужны Node.js 22 и PostgreSQL 16.

```bash
# база данных (если нет своей)
docker run -d --name baiym-db -p 5432:5432 \
  -e POSTGRES_USER=baiym -e POSTGRES_PASSWORD=baiym -e POSTGRES_DB=baiym postgres:16-alpine

cp .env.example .env          # заполните PAYLOAD_SECRET (openssl rand -hex 32)
npm ci
npm run dev                   # http://localhost:3000, админка — http://localhost:3000/admin
```

В режиме разработки схема базы обновляется автоматически.

Если PostgreSQL стоит без Docker (например, на Windows), база должна быть в кодировке UTF-8. Иначе часть символов не сохранится, например «м²» и кыргызские буквы ң, ө, ү: `CREATE DATABASE baiym ENCODING 'UTF8' TEMPLATE template0;`

**Демо-контент.** Пустой сайт можно заполнить текстами из брифа одной кнопкой на главной админки («Загрузить демо-контент») или командой `npm run seed`. Загрузятся 6 услуг с описаниями, этапы, принципы, вопросы и ответы, 5 демонстрационных проектов с чертежами-заглушками, карточки команды «Имя Фамилия» и 3 тестовые заявки. Всё демонстрационное помечено словом «Демо», картинки — штампом «ДЕМО-ИЗОБРАЖЕНИЕ». Команда ничего не перезаписывает: если услуги или проекты уже есть, она ничего не делает.

Полезные команды:

| Команда | Зачем |
| --- | --- |
| `npm run dev` | разработка |
| `npm run build && npm start` | проверить продакшен-сборку локально |
| `npm run typecheck` / `npm run lint` | проверки |
| `npm run generate:types` | обновить `src/payload-types.ts` после изменения коллекций |
| `npm run generate:importmap` | после добавления своих компонентов в админку |
| `npm run migrate:create -- название` | создать миграцию после изменения коллекций |
| `npm run seed` | демо-контент |

## Изменение структуры данных (миграции)

1. Меняете поля в `src/collections/*` или `src/globals/*`.
2. `npm run generate:types` и `npm run migrate:create -- что-изменилось`.
3. Коммитите файлы из `src/migrations` вместе с кодом.
4. На сервере новые миграции применяются автоматически при запуске сайта.

## Деплой на сервер (рекомендуемый вариант)

Нужен VPS с Ubuntu 22.04/24.04, от 2 ГБ памяти и 20 ГБ диска, и домен.

1. **DNS:** записи `A` для `@` и `www` на IP сервера.
2. **Docker:** `curl -fsSL https://get.docker.com | sh`
3. **Подкачка** (нужна для сборки на сервере с 2 ГБ памяти):
   ```bash
   fallocate -l 4G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
   echo '/swapfile none swap sw 0 0' >> /etc/fstab
   ```
4. **Код и настройки:**
   ```bash
   git clone https://github.com/<аккаунт>/bayim_architect.git /opt/baiym && cd /opt/baiym
   cp .env.example .env
   nano .env   # SITE_URL=https://домен, DOMAIN=домен, PAYLOAD_SECRET, POSTGRES_PASSWORD
   ```
5. **Запуск:** `docker compose up -d --build` — первая сборка занимает 5–10 минут. Caddy сам выпустит HTTPS-сертификат.
6. Откройте `https://домен/admin` и создайте первого пользователя: почта и надёжный пароль.
7. При желании нажмите «Загрузить демо-контент».
8. **Бэкапы:** добавьте в cron (`crontab -e`):
   ```
   15 3 * * * cd /opt/baiym && ./scripts/backup.sh >> backups/backup.log 2>&1
   ```
   Копии хранятся 14 дней в `backups/`. Обязательно копируйте их за пределы сервера (rclone в облако, или включите платные снапшоты у хостинга).

**Обновление сайта:** `cd /opt/baiym && git pull && docker compose up -d --build`.

**Логи:** `docker compose logs -f app`.

**Восстановление из копии:**
```bash
docker compose exec -T db pg_restore -U baiym -d baiym --clean --if-exists < backups/db_ДАТА.dump
docker compose exec -T app tar xzf - -C /app < backups/files_ДАТА.tar.gz
docker compose restart app
```

### Важно про домен

Админка работает только по адресу из `SITE_URL`. Caddy перенаправляет `www` на основной домен. Если поменяете домен — обновите `SITE_URL` и `DOMAIN` в `.env` и выполните `docker compose up -d`.

### Альтернатива без своего сервера

Vercel (сайт) + Neon (PostgreSQL) + Cloudflare R2 (файлы, переменные `S3_*`). Подходит, если не хочется администрировать сервер, но для этого проекта VPS дешевле и проще.

## Уведомления о заявках

Каждая заявка сохраняется в админке. Дополнительно можно получать уведомления:

- **Telegram.** Создайте бота у [@BotFather](https://t.me/BotFather), токен впишите в `.env` → `TELEGRAM_BOT_TOKEN`. Напишите боту любое сообщение (или добавьте его в рабочую группу), откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `chat.id`. Впишите его в **Настройки сайта → Уведомления о заявках**. Несколько получателей — через запятую.
- **Почта.** Укажите SMTP в `.env` (`SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`) и адреса получателей в настройках сайта. SMTP также нужен для восстановления пароля в админке.

## Аналитика

ID счётчиков вводятся в **Настройки сайта → Аналитика**: Google Tag Manager, Google Analytics 4, Meta Pixel, Яндекс Метрика. Сайт отправляет события `generate_lead` (заявка), клики по WhatsApp и телефону.

## Файлы

По умолчанию загруженные файлы хранятся на сервере в томах Docker `media` (медиатека) и `private` (вложения к заявкам — доступны только сотрудникам после входа). Чтобы хранить их в S3-совместимом хранилище (Cloudflare R2 и др.), заполните переменные `S3_*`.

## Структура проекта

```
src/
  app/(frontend)/[locale]/   страницы сайта
  app/(frontend)/next/       предпросмотр черновиков, загрузка демо-контента
  app/(payload)/             админка и API (генерируется Payload)
  collections/, globals/     структура данных админки
  components/site/           компоненты сайта
  components/admin/          главная админки, кнопки экспорта и демо-контента
  lib/                       данные, форма заявки, уведомления, словари ru/ky
  migrations/                миграции базы данных
  seed/                      демо-контент и картинки-заглушки
public/                      логотип, иконки, картинка для соцсетей
scripts/backup.sh            резервное копирование
scripts/generate-placeholders.py  картинки-заглушки для демо-контента
```
